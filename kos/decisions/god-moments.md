The peak UX payoff points the plan is optimized around, mapped against the primary flow in
[PLAN.md](../PLAN.md):

1. **Someone Noticed Me** — instant validation when someone follows you (likes are Phase 1, not
   MVP — see [[mvp-scope]]).
2. **I Found My People** — browsing the user directory and following someone; see
   [[user-directory-entry-point]] for why this has to exist in MVP, not just wait for Phase 2
   Search.
3. **This Is Mine** — a profile (name, bio, picture) that feels like personal space.
4. **I'm Part of Something** — conversations and interactions that build community. **Not
   actually delivered by MVP** — there is no reply/comment/like mechanism, only one-way posts
   and one-directional follows. Fully earned once Comments ships (see [[mvp-scope]] cut #1).
   Flagged here on purpose so the gap stays visible instead of getting lost in vision copy.
5. **I Can't Stop Checking** — a fresh feed that pulls you back.

**Decisive two:** #2 (finding people) earns the first follow — without it the app has nothing to
do on day one. #1 (getting noticed) is what pulls someone back a second time. #4 is currently
aspirational, not yet structural — see the flag above.
